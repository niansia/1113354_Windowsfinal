# 詩雲設計規格

## 目標

在 Fusion OS App Center 新增「詩雲」互動式 overlay 應用。App Center 的名稱、說明、標籤與狀態沿用系統 i18n；進入應用後固定使用繁體中文，避免古典詩詞內容被機械翻譯。

## 視覺方向

以使用者提供的「Poetry Cloud」截圖為主要視覺來源：

- 全螢幕深黑、酒紅、胭脂紅與金色星雲背景。
- 中央為可拖曳、縮放、點選的詩人關係星圖，而非一般儀表板。
- 左上是搜尋與維度切換，左下是探索路徑與關係查詢。
- 右側是詩人或作品詳情面板，可捲動瀏覽作品。
- 玻璃面板維持 Fusion OS 的空間感，但應用內的金色書卷氣必須比系統藍色更突出。

## 功能範圍

### 探索與搜尋

- 支援詩人、詩題、詩句與朝代搜尋。
- 支援五絕、七絕、五律、七律、詞、古體與自由等體裁篩選。
- 支援唐、宋、元、明、清與先秦等朝代篩選。
- 搜尋結果同時更新星圖、作品列表與統計。

### 詩人星圖

- Canvas 繪製節點、關係線、星塵與焦點光暈。
- 節點大小依作品數與目前搜尋相關度決定。
- 關係來源包含同朝代、共同意象、唱和/交遊與風格相近。
- 支援拖曳平移、滾輪縮放、點選節點、重設視角。
- 尊重 `prefers-reduced-motion`，關閉持續動畫時仍保留完整功能。

### 詳情與詩作

- 詩人詳情顯示朝代、生卒年、簡介、主題、代表作與作品數。
- 詩作顯示標題、作者、朝代、體裁、全文、意象標籤與簡短本機賞析。
- 提供瀏覽器語音朗讀、複製、收藏與分享文字。
- 收藏使用 `localStorage`，不需要帳號或付費服務。

### 路徑探索

- 選取兩位詩人後，使用廣度優先搜尋找出最短關係路徑。
- 左下列出每一步關係與理由。
- 星圖突出顯示路徑節點與連線。

## 資料架構

- `poetryTypes.ts`：詩人、詩作、關係、搜尋與圖譜型別。
- `poetryCorpus.ts`：內建可離線使用的經典精選資料。
- `poetrySearch.ts`：正規化、搜尋、篩選與排序。
- `poetryGraph.ts`：關係建立、最短路徑與 Canvas 場景配置。
- `poetryAnalysis.ts`：由意象、情緒、季節與體裁產生可解釋的本機賞析。
- 未來大型語料採分片索引與按需載入；首版不在啟動時下載數十萬首詩。

公開語料擴充方向以 MIT 授權的 `chinese-poetry/chinese-poetry` 專案為主。介面只顯示目前實際載入的資料量與可擴充來源，不把參考影片中的 32,657 / 933,857 當成已載入資料。

## 錯誤與降級

- Canvas 不可用時顯示可操作的詩人列表。
- 語音合成不可用時停用朗讀並顯示說明。
- 剪貼簿或分享 API 失敗時回退到選取文字與本機狀態提示。
- 空搜尋結果提供清除條件與熱門詩人捷徑。

## 驗證

- 單元測試涵蓋搜尋、篩選、關係圖、最短路徑、賞析與收藏序列化。
- App catalog 測試涵蓋註冊、入口 i18n 與 overlay wiring。
- 執行 `npx tsc --noEmit`、`npm run test:features`、`npm run build`。
- 使用內建瀏覽器驗證主要互動、響應式版面與 console。
